# Historical experiments

This directory retains research notes, benchmark results, logs, and patches.
The TypeScript engine, agents, experimental candidates, and benchmark executables
have been retired in favor of the Go backend. Commands and source paths in the
older reports describe the original experiments and are historical references.
Their source implementations remain available in Git history.

For current agent comparisons, use `go run ./cmd/arena`; for Go simulation and
search benchmarks, see the repository README. Saved results are preserved.
